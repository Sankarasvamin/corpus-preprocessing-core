# 0002：自包含、格式混杂的合成 fixtures

## 已确认的设计

- `fixture-generator-v2` 保留 240 条、四类别、三类型、四日期和原 19 组注入语义。
- 每条主记录只进入一种原始格式；JSONL、TSV、HTML 各自包含三种记录类型，格式不再等价于类型或类别。
- `dataset_id`、日期、类型、正文和 metadata 来源字段都随原始记录传递；解析器不从 `syn-####`、正文信号或 normalized truth 反推。
- 编码、未知扩展名、空文件和恢复性坏行进入独立 `parser_cases/`，不污染 240 条主数据统计。

## 当前合理假设

- HTML 主 fixture 使用“一行一个 `<article>`”作为受控内存边界；真实网页的 DOM 复杂度留待实际样本校准。
- JSON 数组仅作为小文件兼容路径，允许整体载入；大规模输入应转换为 JSONL。

## 后续需要校准

- 实际来源字段别名、压缩文件、字符集比例及 HTML 嵌套模式。
- ING-09 所需的历史 schema 版本和迁移策略。
